What these numbers mean

Coverage gaps will appear here.

Totals include observed regular files and count hardlinks once. Directory overhead and skipped data are omitted. Allocated estimates use filesystem block metadata; shared APFS extents, compression and snapshots prevent exact physical attribution. These numbers do not establish reclaimable space or safe deletion.

Cloud detection uses metadata hints. Real provider behavior remains unverified; known placeholders and protected stores are skipped. The snapshot is not atomic while other processes change files.

Metadata only. Session data is held in memory and purged on release or exit.
